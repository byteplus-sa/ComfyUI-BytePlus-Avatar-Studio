# Bundled Frontend Notices

The static frontend includes React, React DOM, Scheduler, Lucide React,
adapted shadcn/ui components, Radix primitives and the UI dependencies below.
Tailwind and tw-animate-css contribute compiled CSS. Development-only
JavaScript tooling is not bundled in the installable distribution.

## shadcn/ui And UI Dependencies

Components under `frontend/src/components/ui/` were adapted from the official
shadcn `new-york-v4` registry at
https://ui.shadcn.com/r/styles/new-york-v4/ on November 19, 2026.
Changes include local utility imports, a non-submit Button default, dark-theme
styling, application-controlled dialog closing, and omitted unused exports.
